# Cloud-Based Inventory Management System

**Course:** CSBC 252 - Introduction to Cloud Computing  
**Project Type:** Cloud Computing Capstone Project  
**Platform:** Amazon Web Services (AWS)  

## System Architecture
- **Frontend:** React.js + Bootstrap 5 / Tailwind CSS
- **Backend:** Node.js + Express.js (REST API)
- **Database:** MySQL 8 hosted on Amazon RDS
- **Storage:** Amazon S3 (Product Images)
- **Deployment:** Amazon EC2 + Amazon CloudWatch
