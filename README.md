# Cloud Inventory Management System

A cloud-based Inventory Management System built with React.js, Node.js, Express.js, MySQL, and Amazon Web Services (AWS).

## Technology Stack

- React.js
- Node.js
- Express.js
- MySQL
- Amazon EC2
- Amazon RDS
- Amazon S3
- JWT Authentication
- Git & GitHub
